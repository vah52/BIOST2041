Creating new factor variable

Create a new factor variable to label the treatment groups (1 = control, 2 = drug only, 3 = radiation only, 4 = drug + radiation). We are going to use this variable as our grouping variable in the ANOVA model below. Why is it important that we use the categorical version and not the numeric version in ANOVA?

# create new factor variable
tumor <- tumor %>%
  mutate(Treatment = factor(Group, 
                            levels = c(1, 2, 3, 4), 
                            labels = c("control", "drug only", "radiation only", "drug + radiation")))

head(tumor)

Response: ANOVA compares distinct group means, so continuous data should not be used in ANOVA tests, and if we use numerical values, R would interpret these numbers as continuous variables. Turning these values into factors ensures the variables are discrete.

Null and alternative hypotheses

Response: H0: the median of the tumor sizes is the same across all tumor groups.

HA: At least one group has a different median tumor size.
